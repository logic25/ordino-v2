# SOP — Exporting DOB NOW Objections (for Beacon learning)

**Owner:** assignable to Chris (or any office staffer with DOB NOW access)
**Goal:** pull the objection list for each of our plan-examination jobs so Beacon learns "what gets flagged and how we resolved it." This is a repeatable, batch-able task — no technical skill needed.
**What happens with the files:** Manny/Beacon aggregates and loads them. You only need to *produce the exports* and drop them in the shared folder.

---

## What to export (and what to skip)
- ✅ **Standard Plan Examination jobs** — these go through a DOB plan examiner and get **objections**. These are the ones we want.
- ❌ **Professional Certification (pro-cert) jobs** — SKIP. Pro-cert jobs are self-certified and have **no objections**, so there's nothing to export.
- Rule of thumb: if the job has an **Objections / Appointments** tab with rows in it, export it. If it's pro-cert or has zero objections, skip and note it.

## Steps (per job)
1. Log into **DOB NOW** → open the job/filing.
2. Go to the **"Incomplete / Objections / Appointments"** tab.
3. Click **"Export to Excel."**
4. **Rename the downloaded file to the Job # / filing number** (e.g. `M00123456.xlsx`). ⚠️ The export does **not** include the Job # inside it, so the filename is the only way we know which job it belongs to. This step is critical.
5. Save the file into the shared folder: **`[Google Drive → GLE → Beacon Objection Exports]`** *(Manny: confirm/create this folder and paste the link here).*
6. Mark the job **Done** in the tracking sheet (below).

## The kick-out problem (expected — not your fault)
DOB NOW times out / logs you out after a while ("kick-outs"). **This is normal.** Just:
- Work in **batches** (e.g. 15–20 jobs per sitting).
- When you get kicked out, log back in and continue from the next job on the list.
- The tracking sheet is what keeps us from redoing jobs — always update it.

## Tracking sheet (where we left off)
Keep a simple sheet (Google Sheet or the folder itself) with three columns:

| Job # | Status (Done / Skipped-procert / No-objections) | Date |
|-------|--------------------------------------------------|------|
| *(already done — Batch 1: 7 jobs / 47 objections — Manny has these)* | Done | 2026-08 |
| … pick up from the next job … | | |

**Start point:** Batch 1 (7 jobs) is already exported and loaded. Begin with the **next un-exported Standard Plan Exam job** and work forward. There are on the order of a few hundred plan-exam jobs total, so this is a fill-in-spare-time task over several sittings, not a one-day job.

## Done = tell Manny
When you finish a batch (or run out of jobs), tell Manny the count. He re-aggregates and re-loads Beacon, and Beacon gets smarter about what our jobs get flagged for.

---
*Why this matters (context, not required reading): every objection we feed in makes Beacon better at predicting — before we file — what a given kind of job will get flagged for, and how we fixed it last time. It's our "answer key."*
